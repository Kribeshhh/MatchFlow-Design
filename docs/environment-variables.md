# Environment contract

`.env.example` is development documentation, not a production secret file. Inject production values from a secret manager at runtime. Never use VITE_ variables for secrets, put credentials in image layers/build arguments, or print connection URLs. Validate through `apps/api/src/config/env.ts` at startup; only invalid field names appear in errors.

| Variables                                                                           | Purpose / release requirement                                                                                                                   |
| ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| NODE_ENV                                                                            | production for the deployed API/worker                                                                                                          |
| DATABASE_URL                                                                        | Private PostgreSQL connection, verified TLS, bounded connection_limit/pool_timeout; separate migration identity where feasible                  |
| APP_ORIGIN                                                                          | Exact HTTPS canonical origin for account links and OAuth callback                                                                               |
| CLIENT_ORIGIN                                                                       | Comma-separated exact HTTPS origins; normally only APP_ORIGIN                                                                                   |
| HOST, PORT                                                                          | Container 0.0.0.0 and 3001; public access only through ingress                                                                                  |
| TRUSTED_PROXIES                                                                     | Empty means no trust; explicit actual ingress IPs/CIDRs only. Reject booleans, hop counts and /0                                                |
| LOG_LEVEL                                                                           | info normally; do not enable trace/debug without reviewed privacy handling                                                                      |
| STAFF_MFA_KEY                                                                       | Independent random 32-byte lowercase-hex encryption key, mandatory for staff. Back up separately; replacement requires controlled re-encryption |
| SUPPORT_CONTACT_EMAIL                                                               | Real monitored public support/appeals mailbox                                                                                                   |
| SMTP_HOST, SMTP_PORT, SMTP_SECURE, MAIL_FROM                                        | Required for onboarding/recovery and important email delivery; 587 STARTTLS or provider implicit TLS; production transport requires TLS         |
| SMTP_USER, SMTP_PASSWORD                                                            | Paired secret-managed SMTP credentials when required                                                                                            |
| GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET                                              | Paired optional Google credentials; exact APP_ORIGIN/api/auth/google/callback configured at provider                                            |
| S3_REGION, S3_BUCKET, S3_ACCESS_KEY_ID, S3_SECRET_ACCESS_KEY                        | All-or-none private storage integration; least-privilege bucket/prefix access                                                                   |
| S3_ENDPOINT, S3_FORCE_PATH_STYLE                                                    | Optional HTTPS compatible-provider endpoint and addressing policy; no URL credentials                                                           |
| NOTIFICATION_WORKER                                                                 | true embeds durable worker; false requires a separately monitored worker for notifications/webhooks/domain reconciliation                       |
| WEBHOOK_ENCRYPTION_KEY                                                              | Independent random 32-byte lowercase-hex key; shared across replicas and protected backups                                                      |
| CLOUDFLARE_ZONE_ID, CLOUDFLARE_API_TOKEN, PORTAL_CNAME_TARGET, PORTAL_ORIGIN_SECRET | All-or-none custom-domain integration; narrowly scoped API token and independent random origin secret                                           |
| PORTAL_APEX_ADDRESSES                                                               | Optional explicitly provider-approved addresses only                                                                                            |
| PORTAL_ALLOW_HIDE_ATTRIBUTION                                                       | false unless separately approved platform policy                                                                                                |
| SUPPORT_RETENTION_DAYS, MODERATION_RETENTION_DAYS, AUDIT_RETENTION_DAYS             | Product defaults 90/365/365; legal holds override cleanup; jurisdiction review remains required                                                 |
| TEST_DATABASE_URL                                                                   | Local disposable loopback _test only; never inject into production                                                                              |
| PG_BIN                                                                              | Local/CI PostgreSQL client tools for migration/restore verification                                                                             |
| API_PROXY_TARGET                                                                    | Vite development/test only                                                                                                                      |
| SEED_DEMO_DATA, DEMO_SEED_PASSWORD                                                  | Local explicitly opted-in seed only; forbidden in production                                                                                    |

No global shared session secret is required: browser session tokens are random and database digests are revocable. Do not substitute development MFA/webhook/origin encryption keys in production. Rotate credentials independently; retained encrypted records require old/new-key migration, not blind replacement. Credentials are intentionally missing locally for SMTP, Google, S3 and Cloudflare; their live qualification is a launch blocker for the full advertised feature set.
